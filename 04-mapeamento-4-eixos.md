# Mapeamento nas 4 Direções

Mapeamento das descobertas consolidadas (Fases 1–7) para as quatro categorias solicitadas.

## 1. Descobertas de Inovação Tecnológica
- Sensores passivos multiplexados por frequência (LC/SRR + exceptional points) lendo múltiplos parâmetros sem bateria.
- Eletrônica comestível de frequência (LC/SRR em materiais alimentares + tintas condutivas sprayáveis).
- Smartphone como sensor universal de baixo atrito para gestos, vitais e dados de robótica (Phone2Act e similares).
- Cápsulas/sensores de redox + pH + temperatura no GI.
- Arquitetura em camadas que maximiza dados com mínimo hardware.

## 2. Ativo Comercial Visionário
- **Plataforma dual-use:** app de celular que gera dados de robótica (gestos/manipulação) + monitoramento pessoal de saúde com IA.
- Sensores comestíveis/ingeríveis como produto de consumo ou clínico, com modelos de incentivo (parcerias tipo recompensas por dados).
- Crowdsourcing massivo de dados de demonstração humana via celular (redução drástica de custo de coleta).
- Ecossistema vibecode + open hardware para expansão de sensores.
- Objetos instrumentados passivos (garrafas, mesas, embalagens) que capturam interação.

## 3. Artigos Científicos (base existente)
- Science Advances (2025) – multiplexed wireless sensing com high-order exceptional points.
- ACS Applied Materials & Interfaces (2025) – frequency mapping multimodal.
- Trabalhos de edible electronics e LC/SRR comestíveis (Advanced Engineering Materials, Advanced Materials Technologies, arXiv, 2024–2026).
- GISMO/imec e revisões de ingestible capsules (Device 2025 e estudos first-in-human).
- Artigos e repositórios de coleta de dados de robótica via smartphone (Phone2Act, MobileEgo, Surgical Intelligence Labs, 2025–2026).
- Tintas comestíveis condutivas para strain sensing.

## 4. Desenvolvimento de Produto / MVP
Ver detalhamento completo em `05-mvp-roadmap.md`.

**Resumo rápido:**
- **MVP 0:** só celular (dias).
- **MVP 1:** celular + ESP32 leitor de frequência (1–2 semanas).
- **MVP 2:** + sensor comestível LC/SRR simples.
- **MVP 3:** pipeline dual-use completo (exportação para treino + dashboard).

## Síntese Estratégica
As descobertas mais fortes apontam simultaneamente para **inovação tecnológica** (frequência passiva + comestível + celular) e para **ativos comerciais visionários** (plataforma dual-use). A base científica recente já existe. O caminho de MVP é incremental, de baixo custo e começa quase sem hardware extra.
